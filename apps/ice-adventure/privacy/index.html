Ice Adventure: Offline Game Privacy Policy
Version: 0.4.0 | Updated: September 21, 2026

This game runs offline. It has no accounts, internet permission, ads, purchases, analytics, or tracking SDKs. It does not transmit, sell, or share personal data with the developer or third parties.

On-device information
Stage progress, stars, coins, achievements, outfits, the current run, and control preferences remain on this device and are used only for gameplay. Daily gifts use the device date. Vibration is used for optional haptic feedback.

Retention and deletion
Saves remain until you clear the game's data in Android settings or uninstall the app. Deletion cannot be undone. This version has no cloud saves or cross-device sync.

Run recovery
The game saves a run approximately every 3 seconds and when backgrounded. A restored run waits for you to continue. An unexpected system termination may return to the most recent save. Leaving a stage forfeits unsettled rewards from that run.

Credits
World, hero, and enemy illustrations were generated with AI tools. Level designs, UI, procedural animation, effects, and interaction were created for this project. Music and effects use original synthesis scripts. No asset pack from another commercial game was imported.

Support and external services
If you choose to contact Boot Studio by email, we receive the email address and message you send. We use this information to respond to your request, retain it only as necessary to handle the request or meet applicable obligations, and accept deletion requests at the contact below. The game does not automatically attach device identifiers or diagnostics. This policy page is hosted by GitHub Pages; visiting it may cause the hosting provider to receive ordinary web-request information under its own privacy terms. The game itself does not make these web requests.

Children
The game does not knowingly collect personal information from children or other players. It has no chat, user uploads, behavioral advertising or account system.

Policy updates
If a future version changes how data is handled, we will update this policy before introducing the change.

Juego sin conexión

Información en el dispositivo
El progreso, las estrellas, las monedas, los logros, los colores del personaje, la partida actual y las preferencias se guardan únicamente en este dispositivo para las funciones del juego. Los regalos diarios utilizan la fecha del dispositivo. El permiso de vibración se usa para efectos opcionales que puedes desactivar.

Los datos se conservan hasta que borres los datos del juego en los ajustes de Android o desinstales la aplicación. No pueden recuperarse después de borrarlos. Esta versión no ofrece guardado en la nube ni sincronización entre dispositivos.

La partida se guarda aproximadamente cada 3 segundos y al pasar la aplicación a segundo plano. Al restaurarla, el juego queda en pausa hasta que decidas continuar. Un cierre inesperado puede hacer que vuelvas al último guardado. Abandonar un nivel descarta las recompensas pendientes de esa partida.

Créditos
Las ilustraciones de escenarios, protagonista y enemigos se generaron con herramientas de IA. Los niveles, la interfaz, las animaciones procedimentales y los efectos se crearon para este proyecto. La música y los efectos de sonido utilizan síntesis original. No se importaron paquetes de recursos de otros juegos comerciales.

Asistencia y servicios externos
Si escribes a Boot Studio, recibimos la dirección y el contenido del correo que envías. Los usamos para responder y los conservamos solo durante el tiempo necesario para atender tu solicitud o cumplir obligaciones aplicables. Puedes solicitar su eliminación mediante el contacto indicado abajo. El juego no adjunta automáticamente identificadores del dispositivo ni diagnósticos. GitHub Pages aloja la página pública de esta política; al visitarla, el proveedor puede recibir información habitual de solicitudes web según sus propias condiciones de privacidad. El juego no realiza esas solicitudes.

Menores y cambios
El juego no recopila deliberadamente información personal de menores ni de otros jugadores. No incluye chat, contenido subido por usuarios, publicidad conductual ni cuentas. Si una versión futura cambia el tratamiento de datos, actualizaremos esta política antes de introducir los cambios.

Datenschutzerklärung für Ice Adventure
Version 0.4.0 · Aktualisiert am 21. September 2026

Offline-Spiel
Dieses Spiel benötigt weder ein Konto noch eine Internetberechtigung. Es enthält keine Werbung, In-App-Käufe, Analyse- oder Tracking-SDKs. Es überträgt, verkauft oder teilt keine personenbezogenen Daten mit dem Entwickler oder Dritten.

Daten auf dem Gerät
Fortschritt, Sterne, Münzen, Erfolge, Charakterfarben, die aktuelle Runde und Einstellungen bleiben ausschließlich auf diesem Gerät und dienen den Spielfunktionen. Tägliche Geschenke verwenden das Datum des Geräts. Die Vibrationsberechtigung wird für abschaltbare Rückmeldungen verwendet.

Speicherung und Löschung
Die Daten bleiben gespeichert, bis du die Spieldaten in den Android-Einstellungen löschst oder die App deinstallierst. Die Löschung kann nicht rückgängig gemacht werden. Diese Version bietet keine Cloud-Spielstände und keine Synchronisierung zwischen Geräten.

Runden fortsetzen
Das Spiel speichert die Runde ungefähr alle 3 Sekunden und beim Wechsel in den Hintergrund. Eine wiederhergestellte Runde wartet pausiert auf deine Fortsetzung. Nach einem unerwarteten Systemabbruch kann der letzte Speicherstand geladen werden. Beim Verlassen eines Levels gehen noch nicht verbuchte Belohnungen dieser Runde verloren.

Mitwirkende
Die Illustrationen der Welten, des Helden und der Gegner wurden mit KI-Werkzeugen erstellt. Level, Oberfläche, prozedurale Animationen und Effekte wurden für dieses Projekt entwickelt. Musik und Soundeffekte beruhen auf eigener Klangsynthese. Es wurden keine Ressourcenpakete anderer kommerzieller Spiele importiert.

Support und externe Dienste
Wenn du Boot Studio eine E-Mail schickst, erhalten wir deine Absenderadresse und Nachricht. Wir verwenden diese zur Bearbeitung deiner Anfrage und bewahren sie nur so lange auf, wie dafür oder zur Erfüllung geltender Pflichten erforderlich. Über den unten genannten Kontakt kannst du ihre Löschung anfragen. Das Spiel hängt keine Gerätekennungen oder Diagnosedaten automatisch an. Die öffentliche Seite dieser Erklärung wird von GitHub Pages gehostet. Beim Aufruf kann der Anbieter übliche Web-Anfragedaten nach seinen eigenen Datenschutzbestimmungen erhalten. Das Spiel selbst stellt diese Web-Anfragen nicht.

Kinder und Änderungen
Das Spiel sammelt wissentlich keine personenbezogenen Daten von Kindern oder anderen Spielern. Es bietet keinen Chat, keine Nutzer-Uploads, keine verhaltensbasierte Werbung und keine Konten. Falls eine spätere Version die Datenverarbeitung ändert, aktualisieren wir diese Erklärung vor Einführung der Änderungen.

オフラインゲームについて

端末内に保存する情報
進行状況、星、コイン、実績、キャラクターの配色、進行中の冒険、各種設定を、この端末内にのみ保存してゲーム機能に使用します。毎日の贈り物には端末の日付を使用します。振動権限は任意の操作フィードバックに使われ、設定で無効にできます。

保存期間と削除
データは、Androidの設定から本ゲームのデータを消去するか、アプリをアンインストールするまで保存されます。削除後は復元できません。本バージョンにはクラウド保存や端末間の同期機能はありません。

冒険の再開
約3秒ごと、およびアプリがバックグラウンドに移る際に冒険を保存します。復元された冒険は、再開を選ぶまで一時停止します。予期しないシステム終了が発生すると、直近の保存時点に戻る場合があります。ステージを途中で終了すると、その冒険の未確定報酬は失われます。

制作情報
背景、主人公、敵のイラストはAIツールで生成されました。ステージ、画面、プログラムによるアニメーション、効果は本プロジェクト用に制作しています。音楽と効果音は独自の音声合成によるものです。他の商用ゲームの素材パックは取り込んでいません。
