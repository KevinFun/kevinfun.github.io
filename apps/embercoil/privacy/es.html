Embercoil: Run & Gun

Fecha de entrada en vigor: 22 de septiembre de 2026. Desarrollador y contacto: KevinFun. Paquete Android: xyz.kevinfun.embercoil.

Juego sin conexión

Embercoil es un juego de acción para un jugador. No incluye cuentas, anuncios, compras, analítica, funciones sociales, guardado en la nube ni SDK de rastreo. Puedes jugar sin conexión.

Datos locales

El progreso, las puntuaciones, los logros y los ajustes se guardan solo en el almacenamiento privado de la aplicación. El idioma del dispositivo determina si se muestra inglés, español o chino simplificado; otros idiomas usan inglés. Estos datos no se envían a KevinFun ni a terceros. La aplicación no solicita el permiso de internet de Android.

Recogida y uso compartido

El juego no recoge ni comparte datos personales o sensibles. No accede a contactos, ubicación, fotos, archivos ajenos a su almacenamiento privado, micrófono, cámara, identificadores publicitarios ni otras aplicaciones. No vendemos datos.

Permisos

Se utiliza el permiso normal de vibración de Android para la respuesta háptica opcional, que puede desactivarse en Ajustes. Este permiso no recoge información.

Conservación, borrado y copias

Los datos locales se conservan hasta que uses Ajustes → Borrar progreso local, borres los datos en los ajustes de Android o desinstales el juego. El borrado dentro del juego también elimina los ajustes y la copia local de recuperación. La copia automática de Android está desactivada. No hay copia del progreso en un servidor y no podemos recuperarlo.

Sitio web y correo de asistencia

Solo al pulsar un enlace se abre tu navegador o aplicación de correo. GitHub Pages aloja este sitio mediante HTTPS, sin analítica ni cookies añadidas por KevinFun y sin inicio de sesión. GitHub puede procesar datos técnicos como la dirección IP según su política. Si nos escribes, recibimos tu dirección y el contenido que envíes. Se usan solo para atender la solicitud; no se venden ni se usan para publicidad. Borramos los mensajes en los 90 días siguientes a la resolución, salvo obligación legal. Puedes solicitar su eliminación antes.

Público

El juego muestra combate estilizado entre máquinas, sin sangre ni lesiones humanas. Está pensado para adolescentes y adultos, no específicamente para menores de 13 años. No recogemos intencionadamente datos personales de menores. Si crees que nos han enviado datos de este tipo, contáctanos para eliminarlos.

Seguridad y cambios

Los archivos locales están protegidos por el aislamiento de almacenamiento de Android. No se transmiten datos del juego. Publicaremos aquí cualquier cambio con una nueva fecha. Si cambian las prácticas de datos, actualizaremos la aplicación y las declaraciones de Google Play antes de aplicarlas.
